1. О ПРОЕКТЕ
--------------------------------------------------------------------------------

SOLE SOCIETY — это одностраничный интернет-магазин кроссовок, созданный как
портфолио-проект для демонстрации навыков вёрстки, работы с DOM, состояния
приложения, фильтрации, LocalStorage и адаптивного интерфейса.

Проект имитирует полноценный e-commerce: каталог с фильтрами, корзину
с сохранением, избранное, поиск, карточку товара, оформление заказа.
Все интерактивные элементы действительно работают — кнопок-заглушек нет.

ВАЖНО: это концептуальный демонстрационный проект. Все товары, бренды, цены,
условия доставки и контакты вымышлены. Реальная оплата не производится,
заказы никуда не отправляются.

3. ТЕХНОЛОГИИ
--------------------------------------------------------------------------------

    - HTML5 — семантическая разметка, SVG-спрайт иконок, aria-атрибуты.
    - CSS3 — кастомные свойства, Flexbox, CSS Grid, aspect-ratio,
      backdrop-filter, медиазапросы, @keyframes, prefers-reduced-motion.
    - Vanilla JavaScript (ES2015+) — без библиотек и фреймворков.
      Работа с DOM, делегирование событий, IntersectionObserver,
      localStorage, Intl.NumberFormat.

Никаких зависимостей. Единственная внешняя загрузка — шрифты Google Fonts
(Unbounded и Inter) и изображения с Unsplash.

ИЗБРАННОЕ
    - Добавление и удаление товаров.

ПОИСК

    - Микроанимации карточек при наведении.
    - Пульсация счётчиков корзины и избранного.
    - Уважение настройки prefers-reduced-motion.

6. ЗАПУСК ЛОКАЛЬНО
--------------------------------------------------------------------------------

СПОСОБ 1. ПРОСТО ОТКРЫТЬ ФАЙЛ

    1. Скачай или склонируй репозиторий.
    2. Открой index.html двойным кликом в браузере.

    Всё работает без сервера. Единственное ограничение — некоторые браузеры
    могут блокировать localStorage при открытии через file://.
    Если корзина не сохраняется, используй способ 2.

СПОСОБ 2. ЛОКАЛЬНЫЙ СЕРВЕР

    Через Python:

        python3 -m http.server 8000

    Через Node.js (если установлен npx):

        npx serve .

    Открой в браузере:

        http://localhost:8000

7. ПУБЛИКАЦИЯ НА GITHUB PAGES
--------------------------------------------------------------------------------

    1. Создай новый репозиторий на GitHub, например sole-society.
    2. Загрузи файлы index.html, style.css, script.js, README.txt
       в корень репозитория.

    Через командную строку:

        git init
        git add .
        git commit -m "Initial commit: SOLE SOCIETY storefront"
        git branch -M main
        git remote add origin https://github.com/<твой-ник>/sole-society.git
        git push -u origin main

    3. Открой репозиторий на GitHub → Settings → Pages.
    4. В блоке Build and deployment:
         Source:  Deploy from a branch
         Branch:  main
         Folder:  / (root)
    5. Нажми Save.
    6. Через 1–2 минуты сайт будет доступен по адресу:

        https://<твой-ник>.github.io/sole-society/

    - Нет горизонтальной прокрутки.
    - Кнопки удобного размера для касания.
    - Фильтры открываются отдельной панелью.
    - Корзина и модалки адаптированы под узкий экран.

10. ДОСТУПНОСТЬ
--------------------------------------------------------------------------------

    - Семантический HTML: header, nav, main, section, footer, article.
    - Все кнопки имеют aria-label или видимый текст.
    - Поля формы связаны с label через for / id.
    - Модальные окна используют role="dialog", aria-modal="true",
      aria-labelledby.
    - Изображения имеют осмысленные alt.
    - Навигация с клавиатуры: Tab, Enter, Escape.
    - Видимый фокус через :focus-visible.
    - Поддержка prefers-reduced-motion — анимации отключаются
      для пользователей, которые предпочитают уменьшенное движение.
    - Ссылка «Перейти к содержимому» для скринридеров
      и клавиатурной навигации.

11. ДАННЫЕ И ХРАНЕНИЕ
--------------------------------------------------------------------------------

МАССИВ ТОВАРОВ

    Все товары описаны в script.js в массиве PRODUCTS.
    Каждый товар содержит:

        id           Уникальный идентификатор
        name         Название
        category     Категория
        price        Текущая цена
        oldPrice     Старая цена (или null)
        badge        Бейдж: new, sale, bestseller или null
        popularity   Популярность для сортировки
        dateAdded    Условная новизна
        sizes        Доступные размеры
        image        URL изображения
        description  Описание

LOCALSTORAGE

    Данные сохраняются под ключами:

        sole-society:cart        Содержимое корзины
        sole-society:favorites   Избранные товары

    Корзина и избранное не теряются после перезагрузки страницы
    и работают офлайн.

12. ВАЖНЫЕ ОГОВОРКИ
--------------------------------------------------------------------------------

Это демонстрационный концептуальный проект. Он не является настоящим
магазином и не должен восприниматься как реальное коммерческое предложение.

    - Все названия моделей, бренды и цены вымышлены.
    - Товары не выдаются за продукцию реальных производителей.
    - Реальная оплата не производится.
    - Заказы не отправляются и не обрабатываются.
    - Форма оформления заказа существует только для демонстрации
      интерфейса.
    - Условия доставки, возврата и поддержки — условные
      и не являются обязательствами.
    - Контакты в подвале — заглушки.
    - Ссылки на соцсети — демонстрационные, ведут на якорь главной
      страницы.

Проект создан для портфолио и учебных целей.
